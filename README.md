# 摸摸鱼

私人手账 · 摸摸鱼。

## 启动

```bash
cd <本项目文件夹>
npm install
npm run dev
```

浏览器打开终端里的地址（一般是 http://127.0.0.1:5173/）。

## 主要文件在哪

- `src/pages/` — 今天 / 知识 / 回顾 / 我的
- `src/components/` — 小鱼、图标、底部导航
- `src/sheets/` — 弹层表单
- `src/store/` — 数据与 localStorage
- `src/index.css` — 颜色与全局样式
- `index.html` — 入口

旧版静态页面备份在 `legacy-static/` / `html-app/`。
