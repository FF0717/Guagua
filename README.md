# 正经摸鱼

每天学一个你不知道的小知识，打卡、记笔记、看日历和周月年总结。

做成了**手机网页**，可以在 iPhone 上「添加到主屏幕」，外观接近 App。

## 功能

- 今日打卡：标题 + 分类 + 知识笔记 + 可选来源
- 知识卡片：点进看完整笔记
- 打卡日历：按月热力显示学了多少
- 本周 / 本月 / 今年总结：数量、打卡天数、最长连续
- 连续打卡统计
- 随机复习：翻一张以前的卡片
- 数据保存在手机浏览器本地（不上传）

## 在 iPhone 上怎么用

页面需要通过网址打开（不要直接用文件点开）。最简单两种：

### 方法 A：电脑开一个本地服务（同一 Wi‑Fi）

在项目文件夹里执行：

```bash
cd ~/Desktop/一日一知
python3 -m http.server 8765
```

1. 看电脑的局域网 IP（系统设置 → Wi‑Fi → 详情里的 IP，例如 `192.168.1.8`）
2. iPhone 用 **Safari** 打开：`http://192.168.1.8:8765`
3. 点底部分享 → **添加到主屏幕** → 添加

### 方法 B：以后挂到网上

把整个文件夹部署到任意静态空间（GitHub Pages、Vercel、腾讯云静态网站等），用 HTTPS 链接在 Safari 打开，再添加到主屏幕。
